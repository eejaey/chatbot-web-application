# 🤖 Chatbot Web Application

A full-stack chatbot web application that delivers real-time conversational responses through a clean browser interface.  
This project demonstrates frontend UI development, backend chatbot logic, and containerized deployment using Docker.

Built as a learning and portfolio project to showcase web development, API integration, and chatbot architecture.

---

## ✨ Features

- 💬 Interactive browser chat interface  
- 🧠 Backend chatbot logic (Python)  
- ⚡ Responsive frontend using HTML, CSS, and JavaScript  
- 🐳 Docker container support  
- 🔧 Environment-based configuration  
- 🌐 Ready for local or cloud deployment

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/eejaey/chatbot-web-application.git
cd chatbot-web-application
````

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the application

```bash
python app.py
```

Open your browser and navigate to:

```
http://localhost:5000
```

---

## 🐳 Run with Docker

### Build the image

```bash
docker build -t chatbot-app .
```

### Run the container

```bash
docker run -p 5000:5000 chatbot-app
```
